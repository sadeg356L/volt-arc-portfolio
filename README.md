# نواة — استوديو تصميم وتطوير مواقع

موقع تعريفي عربي (RTL) لاستوديو تونسي متخصص في تصميم وتطوير مواقع الشركات والمتاجر الإلكترونية وصفحات الهبوط وتحسين تجربة المستخدم.

الموقع مبني كملف HTML واحد، من دون خطوة بناء أو حزم npm. يحتفظ بتجربة التمرير السينمائية الأصلية: GSAP ScrollTrigger، Lenis، ومشهد Three.js إجرائي اختياري. استُبدلت هوية قالب VOLT Arc بالكامل بهوية «نواة».

## التشغيل

```bash
cd volt-arc-landing-page-template
python -m http.server 8000 --bind 127.0.0.1
```

ثم افتح:

```text
http://127.0.0.1:8000/
```

يمكن أيضًا فتح `index.html` مباشرة، لكن تشغيل خادم محلي أفضل لأن Three.js يُحمَّل كوحدة ES عبر import map.

| --- | --- | --- |

| البريد الإلكتروني | `data-email` على `<body>` | القيمة الحالية: `sadegtrabelsi39@gmail.com`. تُستخدم في كل روابط البريد. |
| النصوص التجريبية للأعمال | قسم «أعمالنا» | العناوين والأسماء والواجهات هي **نماذج تجريبية** وليست أعمال عملاء حقيقيين. لا تحذف عبارة «نموذج تجريبي» إلا بعد استبدالها بمشاريع حقيقية موثّقة. |

كل روابط واتساب والبريد تُبنى وقت التشغيل من القيمتين في `<body>`. توجد أيضًا نسخ احتياطية ثابتة داخل `href` في بطاقة التواصل والزر العائم، حتى تظل روابط التواصل صالحة عند تعطيل JavaScript؛ حدّثها مع القيمتين الأساسيتين إن غيّرت الرقم أو البريد.

## سلوك نموذج التواصل

- التحقق من الحقول يتم في المتصفح فقط.
- عند نجاح التحقق، يفتح الموقع واتساب برسالة مُجهّزة تحتوي على الاسم والبريد ونوع المشروع والهاتف والتفاصيل.
- **لا يوجد خادم أو قاعدة بيانات، ولا تُرسل البيانات تلقائيًا.** يظل المستخدم هو من يرسل الرسالة من واتساب.
- إذا مُنع فتح النافذة، تظهر روابط بديلة لفتح واتساب أو إرسال الرسالة عبر البريد.
- عند تعطيل JavaScript، يُخفى النموذج وتظهر ملاحظة بالبريد ورقم واتساب، وتبقى روابط التواصل المباشرة صالحة.

## الأقسام

- واجهة رئيسية بعنوان «حضورٌ رقمي يليقُ بطموحك» ودعوة «اطلب موقعك الآن».
- منهج العمل ثم مشهد ثلاثي الأبعاد يشرح أربع طبقات: الهوية، التجربة، البرمجة والأداء، التحسين والحماية.
- خدمات: مواقع الشركات، المتاجر الإلكترونية، صفحات الهبوط، تحسين تجربة المستخدم.
- معرض أعمال أفقي بنماذج تجريبية موسومة بوضوح.
- «لماذا نواة؟»: السرعة، التصميم، التوافق مع الهواتف، سهولة الاستخدام.
- مراحل العمل الخمس: نفهم، نرسم، نطوّر، نختبر، نسلّم.
- أسئلة شائعة عن التكلفة والمدة والصيانة والملكية والعمل عن بُعد.
- تواصل عبر واتساب أو نموذج يجهّز الرسالة.
- تذييل كامل وزر واتساب عائم.

### أصول غير مستخدمة

الملفات التالية بقيت من القالب الأصلي ولم يعد الموقع يستخدمها:

- `assets/motor.js`
- `assets/*.webp` و`assets/*.png` (صور الدراجة النارية)
- `.github/assets/*` (صور README القديمة)

لا تؤثر على تشغيل الموقع. يمكن حذفها قبل النشر لتقليل حجم المشروع، أو الاحتفاظ بها إن أردت الرجوع للقالب الأصلي. راجع `LICENSE` قبل إعادة استخدام أي منها.

## التقنيات

- HTML5 وCSS خالص (متغيرات CSS، Grid، Flexbox، تأثيرات CSS فقط للمحاكيات).
- JavaScript ES modules.
- [GSAP 3.12.5](https://gsap.com/) + ScrollTrigger — حركة التمرير والمشاهد المثبتة.
- [Lenis 1.1.13](https://github.com/darkroomengineering/lenis) — تمرير سلس.
- [Three.js 0.165.0](https://threejs.org/) — نواة رقمية إجرائية، بلا ملفات نموذج ثلاثي الأبعاد.
- [Phosphor Icons](https://phosphoricons.com/) و[خط Tajawal](https://fonts.google.com/specimen/Tajawal) عبر CDN.

جميع المكتبات تُحمَّل عبر CDN من دون bundler. راجع نسخ المكتبات وثبّتها محليًا إذا كانت سياسة النشر تتطلب ذلك.

## الأداء والتوافق

- Three.js يُستورد ديناميكيًا، والمشهد ثلاثي الأبعاد **اختياري**.
- عند غياب WebGL أو فشل تحميل Three.js، تُضاف حالة `no-gl` ويظهر بديل CSS متوهج مع بقاء التمرير والتنقل والنموذج تعمل.
- يتم فحص WebGL قبل إنشاء المشهد، مع تحرير سياق الفحص.
- يتم خفض دقة العرض تدريجيًا عند بطء الإطار، مع حد أدنى مناسب للشاشات الضعيفة.
- عند `prefers-reduced-motion: reduce`: يُلغى التمرير السلس والتثبيت والحركات المتتابعة، ويبقى المحتوى والمعرض قابلين للوصول.
- عند تعطيل JavaScript: يُخفى المحمّل والعناصر التفاعلية غير الضرورية، ويظهر المحتوى الأساسي والمعرض القابل للتمرير أفقيًا، مع ملاحظة تواصل مباشرة بدل النموذج.
- لا توجد طلبات شبكة لجلب بيانات أو صور منتجات؛ المحاكيات واللوحات كلها CSS.
